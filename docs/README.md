# Project documentation index

Read documents in this order:

1. `../AGENTS.md` — concise working rules.
2. The active numbered file in `discussions/` — current scope and status.
3. `PROJECT_BRIEF.md` — durable project direction.
4. `memory.md` — user-approved fixed instructions.
5. `queue.md` — future/unstarted work.
6. `issues_and_fixes.md` — reusable problem history.
7. `reference/` — detailed background consulted only when needed.

## Discussion sequence

- Use `NNN_short_topic.md`, starting at `001`.
- Never renumber an existing discussion.
- One discussion owns one bounded task or decision area.
- Add scope ideas to `queue.md` instead of silently adding them to active work.
- At completion, record the outcome, verification, remaining issues, and follow-up queue IDs.
- The lowest-numbered discussion without a terminal status is the active discussion unless the user explicitly selects another.
